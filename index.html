Vacation Scheduler

Vacation Scheduler is an Android application for organizing vacations and their associated excursions. Users can manage vacation dates and lodging information, track excursions, search saved vacations, generate reports, and schedule notifications for important dates.

Installation

  1. Download the Vacation Scheduler APK to an Android device.
  2. Open the downloaded APK file.
  3. If prompted, allow installation of applications from the browser or file manager being used.
  4. Follow the Android installation prompts.
  5. Open Vacation Scheduler after installation is complete.

Application Data

Vacation Scheduler stores vacation and excursion information locally on the Android device using Room and SQLite.
